# Graphs and Visualization Guide

## Where Are My Graphs?

The graphs/visualizations are served by the **Web Visualization Server**.

### Option 1: Launch Web Server (3D Visualization)

```bash
cd "/home/monk/Work/9th Planet"
./venv/bin/python3 src/viz/server.py
```

Then open your browser to: **http://localhost:5000**

You will see:
- **3D Solar System** (Sun, Giants, eTNOs, Planet 9)
- **Animated orbits** using Three.js
- **Time display** showing simulation progression

### Option 2: Use Docker

```bash
# Build & Run with Docker Compose
docker-compose up web-viz

# Or build manually
docker build -t planet9 .
docker run -p 5000:5000 -v $(pwd)/data:/app/data planet9 python src/viz/server.py
```

Then visit: **http://localhost:5000**

## What Data is Visualized?

The web server reads `data/simulation.h5` (generated by the simulation) and displays:
- **Positions of all particles** over time
- **Planet 9's orbit** (the candidate solution)
- **eTNO clustering** (visual proof of alignment)

## Accessing Graphs During Optimization

**Real-time Logs**: The TUI Dashboard shows:
- Best Cost ($\sigma_\varpi$)
- System status
- Live logs from `logs/optimizer.log`

**Post-Run Analysis**: After optimization completes:
1. Launch the web server
2. The 3D view shows the **BEST universe** (lowest clustering variance)

## Alternative: Plot with Python

If you want static plots instead of 3D:

```python
import h5py
import matplotlib.pyplot as plt

# Load simulation data
with h5py.File('data/simulation.h5', 'r') as f:
    times = f['time'][:]
    positions = f['positions'][:]  # [Time, Particle, 3]
    
# Plot X-Y orbits
plt.figure(figsize=(10, 10))
for i in range(positions.shape[1]):
    plt.plot(positions[:, i, 0], positions[:, i, 1], alpha=0.7)
plt.xlabel('X (AU)')
plt.ylabel('Y (AU)')
plt.title('Solar System Orbits')
plt.axis('equal')
plt.grid(True)
plt.savefig('orbits.png')
```
